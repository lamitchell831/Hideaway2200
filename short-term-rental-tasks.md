# Short-Term Rental (Tiny House) Master Task List
**Start Date:** March 26, 2026 | **Target Launch:** TBD (8-12 weeks typical)

---

## PHASE 1: LEGAL & ADMINISTRATIVE (Week 1-2)

### Legal Requirements (North Carolina)
- [ ] Research local zoning laws for short-term rentals (county + city level)
- [ ] Check HOA rules (if applicable) for short-term rental restrictions
- [ ] Apply for zoning permit or special use approval
- [ ] Obtain business license from local municipality
- [ ] Register with NC Department of Revenue for tax collection
- [ ] Apply for short-term rental permit (if required by county)
- [ ] Post zoning/permit number on property and in all ads (if required)
- [ ] Research and understand NC state occupancy taxes (6-7% typical)
- [ ] Set up tax collection system (Airbnb/VRBO auto-collect or manual)
- [ ] Create LLC or business entity (optional but recommended)
- [ ] Get EIN from IRS for business
- [ ] Open business bank account

### Insurance & Protection
- [ ] Research short-term rental insurance providers (Proper, Safely, CBIZ)
- [ ] Get liability insurance ($1M minimum, $2M recommended)
- [ ] Check if homeowner's insurance covers STR (probably not)
- [ ] Document property condition with photos/video
- [ ] Create house rules and rental agreement
- [ ] Set up security deposit policy

---

## PHASE 2: PROPERTY SETUP & UTILITIES (Week 2-4)

### Utilities & Infrastructure
- [ ] Set up dedicated WiFi (business-grade router, mesh system)
- [ ] Ensure reliable cell service or install signal booster
- [ ] Set up smart lock (August, Yale, or Schlage Encode)
- [ ] Install outdoor security cameras (Ring, Arlo, or Nest)
- [ ] Set up smart thermostat (Nest or Ecobee)
- [ ] Verify water/electric/septic can handle guests
- [ ] Install outdoor lighting (pathway, porch, parking area)
- [ ] Set up trash/recycling removal schedule
- [ ] Create guest WiFi network (separate from personal)
- [ ] Test internet speed (minimum 25 Mbps for good reviews)

### Safety & Compliance
- [ ] Install smoke detectors (required: every bedroom + common area)
- [ ] Install carbon monoxide detector (if any gas appliances)
- [ ] Install fire extinguisher (kitchen + accessible location)
- [ ] Create emergency exit plan (post on back of door)
- [ ] First aid kit (stocked + visible location)
- [ ] Flashlight + batteries in drawer
- [ ] Test all electrical outlets
- [ ] Install GFCI outlets near water sources
- [ ] Check plumbing for leaks
- [ ] Post emergency numbers (911, poison control, your contact)

## NC-SPECIFIC NOTES

- **Occupancy Tax:** NC requires 6-7% occupancy tax on rentals
- **Local Variations:** Mountain towns (Asheville, Boone) have stricter rules than rural areas
- **Zoning:** Many NC counties require special use permits for STRs
- **HOAs:** Common in NC mountain areas; check bylaws carefully
- **Insurance:** NC coastal areas may have hurricane/wind exclusions

**Next Action:** Start with legal research for your specific county/city.
